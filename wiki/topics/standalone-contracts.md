# Standalone accessibility contracts

Projects pin the npm package, run init once, and discover individual records through the index. Pattern lookup expands semantic dependencies and preserves evidence routes. The optional UI adapter checks the pinned public catalog before mapping canonical slugs. [Consumer commands](../../README.md)

The personal release series starts at 1.0.0. The upstream revision is the provenance for imported standards and tests. Historical Verndale deliveries belong to the upstream project. [Source attribution](../../NOTICE.md)

For disclosure navigation, verify the explicit control relationship when supplied and test expanded state through each dismissal path. APG permits optional aria-controls for the generic disclosure. The navigation example illustrates using it. Check the target browser and assistive technology pairing. [APG disclosure](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/) · [Navigation example](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/examples/disclosure-navigation/)

For native popovers verify the invoker and actual dismissal behavior for the selected popover type. For visual focus, test a forced-colors presentation because the browser can remove box shadows. These are implementation and verification practices. [HTML popovers](https://html.spec.whatwg.org/multipage/popover.html) · [MDN forced colors](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/forced-colors)
