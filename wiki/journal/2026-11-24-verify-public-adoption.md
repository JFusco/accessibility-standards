# Verify adoption from the public 1.0.0 release

The packed-consumer gate covers only a local tarball. An empty npm project with an existing `AGENTS.md` therefore installed `accessibility-standards@1.0.0` by exact version from the public registry. The lockfile recorded the registry tarball and its `sha512` integrity, which matches `npm view`. `npm audit signatures` verified the registry signature and provenance attestation. The second `init` left the instructions and managed block byte-for-byte unchanged. Offline `resolve pattern.dialog` returned focus, keyboard, naming and evidence-route guidance with `provenance.package` set to `accessibility-standards@1.0.0`. The README now includes this versioned example.
