# Accept the APG practices index baseline

The first full scan reported the APG practices index as unreviewed. A fresh retrieval produced the observed digest. The index still lists the same seven practices, in the same order, that the APG coverage manifest maps. Those are landmark regions, names and descriptions, keyboard interface, grid and table properties, range-related properties, structural roles and hiding semantics. The index only links to those pages. Each practice page keeps its own reviewed digest, so the 16 affected semantic records need no contract change. The accepted digest is now in the reviewed baseline. [Source review](https://github.com/JFusco/accessibility-standards/issues/5) · [Official index](https://www.w3.org/WAI/ARIA/apg/practices/)
